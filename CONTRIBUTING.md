# Contributing

Thanks for considering a contribution!

## Ways to contribute

- Report a bug or usability issue.
- Suggest a feature or design improvement.
- Improve documentation.
- Submit a focused pull request.

## Before opening a pull request

1. Search existing issues to avoid duplicates.
2. For substantial changes, open an issue first to discuss the approach.
3. Keep pull requests focused and explain the motivation.
4. Test the website locally using `python3 -m http.server 8080`.
5. Check desktop and mobile layouts.
6. Inspect the browser console for errors.
7. Never commit API tokens, credentials, private keys, or private repository data.

## Code style

- Use clear, descriptive names.
- Prefer simple vanilla JavaScript and CSS unless a dependency is justified.
- Keep the project build-free where possible.
- Preserve keyboard accessibility and responsive behavior.
- Update documentation when behavior or configuration changes.

## Pull request checklist

- [ ] The change addresses one clear goal.
- [ ] Existing features still work.
- [ ] The page has been checked at desktop and mobile widths.
- [ ] Documentation has been updated where necessary.
- [ ] No secrets or generated clutter were committed.

By contributing, you agree that your contribution will be provided under the project's MIT License, unless stated otherwise in writing.
